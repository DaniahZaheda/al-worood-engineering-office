# Al-Worood Engineering Office

A modern Arabic website for Al-Worood Engineering Office, designed to showcase the office's identity, architectural services, projects, and professional work.

## 📌 About the Project

This project is a professional portfolio and informational website for Al-Worood Engineering Office.

The website focuses on presenting the office's architectural vision, services, projects, and contact information through a modern, elegant, and responsive user interface.

The website content is presented in Arabic with full RTL support.

## ✨ Planned Features

- Arabic RTL interface
- Modern and elegant architectural design
- Fully responsive layout
- Office introduction
- Services section
- Projects portfolio
- Project categories and filtering
- Project details and image gallery
- Architect profile
- Contact section
- WhatsApp integration
- Instagram and Facebook links
- Interactive text-based chatbot
- Smooth animations and transitions
- Mobile-friendly navigation
- Basic SEO optimization

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Font Awesome
